# 15기 종료 이후 서비스 연속성

## Status

Proposed. 운영 방향·비용·회원 데이터 보존기간에 대한 사람의 승인이 없다.

## Context

기수 종료와 1인 운영 공백은 별개다. 로그인 수단, 제휴 유효기간, 운영 권한, 백업·개인정보 파기 책임을 정한 뒤 지속 여부를 결정해야 한다.

## Alternatives

| 선택지 | 필요한 합의 | 영향 |
| --- | --- | --- |
| 현 기수 중심 계속 운영 | 운영자·비용·기간·제휴 갱신 | 기존 회원 흐름 유지와 운영 부담 |
| 후속 운영자에게 인계 | 수신자 권한·과업 재현·비밀 갱신 | 운영 책임 이전, 접근 철회 필요 |
| 읽기 전용 또는 종료 | 종료 시각·안내·데이터 파기·백업 폐기 | 쓰기/인증 제한과 복구 필요성 평가 |

## Decision

미결정. 승인 전에는 계정·데이터·도메인·기수 기준을 변경하지 않는다.

## Consequences and Questions

승인 주체, 서비스 기간, 갱신 비용, 회원 안내 시점, 로그인 대안, 제휴처 동의, 개인정보 보존/파기, 외부 사본·키 폐기, 인계 수신자와 복구 시험의 완료 기준을 확인한다. 실행과 인계는 [운영 연속성 절차](../operations/runbooks/operations-continuity.md)를 따른다.
