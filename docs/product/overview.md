# 서비스 개요

싸트너십은 SSAFY 구성원이 제휴처를 찾고 자신에게 허용된 혜택을 이용하도록 돕는다. 운영자는 회원 자격과 제휴 정보를 관리하고, 파트너 담당자는 소속 회사의 제휴와 변경 요청을 처리한다.

## 대상과 핵심 가치

| 역할 | 주요 과업 | 확인 수준 |
| --- | --- | --- |
| 방문자 | 캠퍼스·조건에 맞는 공개 제휴 탐색 | 기존 제품 계약 |
| 회원 | 자격 확인, 대외비 혜택 확인, 쿠폰·리뷰·알림 이용 | 기존 제품 계약 |
| 지역 운영자·관리자 | 권한·캠퍼스 범위 내 회원·제휴·요청 운영 | 기존 제품 계약 |
| 파트너 담당자 | 연결 회사의 정보·변경 요청·플랜 관리 | 기존 제품 계약 |

관찰된 사용자 행동 빈도나 이탈률을 측정한 표가 아니다. 추가 조사에서는 관찰·명시적 요청·검증 전 가설을 구분하고 출처를 기록한다. 확인되지 않은 페르소나를 만들지 않는다.

## 범위와 비목표

서울 캠퍼스와 역삼역 주변 제휴 탐색에서 시작했고 여러 캠퍼스의 제휴를 다룬다. 기능 범위는 [기능 인벤토리](./feature-inventory.md), 용어는 [용어집](./glossary.md), 탐색은 [IA](./information-architecture.md)가 맡는다. 빠른 개선과 낮은 운영 비용을 우선한다.

일반 대중에게 모든 회원 혜택을 공개하거나, 파트너에게 타 회사 운영 권한을 제공하지 않는다. 문서 정비가 새로운 혜택·자격·보존기간을 승인하는 것은 아니다.

## 성공을 판단하는 방법

대표 과업은 탐색 → 상세 → 필요한 인증 → 원래 과업 복귀다. 성공 신호는 검색 조건 보존, 허용 대상에게만 혜택 노출, 과업 재개 가능 여부다. 사용률·전환율 목표는 아직 이 문서에서 승인하지 않는다. 실제 지표를 추가할 때 분자·분모·대상·제외 조건·기간·데이터 원천을 함께 정의한다. 기술 이벤트는 [로깅 정본](../architecture/event-logging.md)을 따른다.
