## 증거 구분

기준선 로컬 Node: 1,907개 중 1,898 통과, 기존 플랫폼 조건 skip 9, 실패 0, 약 5.52초. 최근 CI 3건의 전체 E2E 120개는 6.3~9.8분이었다. 로컬과 CI의 시간은 직접 비교하지 않는다. 변경 전 로컬 E2E는 119 통과/1 실패(기존 단순 등록 렌더의 30초 navigation 제한), 총 8.9분이었다. 실제 5단계 등록 과업 검사는 통과했다. 실패 trace/report를 보존했고 변경 후 성공 실행과 직접 속도 개선율로 비교하지 않는다. 삭제 후 발견 목록은 E2E 76개로, 44개(36.7%) 감소했다. 변경 후 Node 1,881개 중 1,872 통과/기존 플랫폼 조건 skip 9/실패 0, 단위 133개 통과, Production 빌드 및 E2E 76개 전부 통과(실패·skip·retry 0, 로컬 7.6분), 문서 106개 검사를 확인했다. 전체 로그의 Fast Refresh 3건은 첫 보호 경로 1건과 관리자 전환 2건이며 동반 runtime 오류는 없었다. CI·dev/main·실제 배포 완료 증거는 [Issue #474](https://github.com/MyKnow/ssartnership/issues/474)의 exact-SHA 기록이 정본이다. 아래 미완료 표시는 이 로컬 제출 시점 기준이며 배포 완료를 미리 주장하지 않는다.

## 잔여 위험

삭제한 비핵심 시각/문구 회귀는 자동 감지하지 않는다. 정책·중요 행동·수동 UI QA는 유지한다. 새 문서가 법적 보존기간·SLO·실환경 권한 검증을 대신하지 않는다.
